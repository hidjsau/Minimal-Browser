STEP 1 - Build skeleton
1. Upload every file in this zip to the ROOT of your GitHub repo (the .github folder too).
   If .github/workflows/build.yml does not upload, create it via "Add file > Create new file"
   with the name .github/workflows/build.yml and paste the contents.
2. Open the Actions tab > "Build APK" > Run workflow (it also runs on every push).
3. When green, open the run, download the artifact "minimal-candy-browser-apk", unzip, install the APK.
4. Test: see the pass conditions in the chat message.
