v14 - what changed (on top of v13)

Top bar
- Slim: address bar 36dp, smaller text, 20dp icons, buttons 40x44dp.
- Reload button next to the tab button; becomes X (stop) while a page loads.
- "Reload" removed from the 3-dot menu. Menu icons are vector drawables (ic_*.xml).

Save file pop-up
- Header (download badge, "Save file", source site), outlined name/type fields,
  smaller cursor buttons, "Save to" folder card with Change, and the switch
  "Download automatically next time".

Folder + auto-download
- Default folder: public Downloads (no picker). Change picks another folder; it is remembered.
- Auto-download ON: no pop-up, "Saving to ..." toast, straight to the remembered folder.
- Menu: "Auto-download: On/Off" toggles it any time.
- Remembered folder deleted / access lost: app asks for a folder again.

Download notification card
- File name, destination folder, "42% . 3.1 MB of 7.4 MB", theme colour.
- Done: "Download complete . 7.4 MB . Tap to open" (opens the file). Failures show the reason.

Text size (menu: "Text size: N%")
- Slider 50-300% (1% steps), live, big readout; "Exact size" box + Reset.
- Out-of-range numbers snap to the nearest limit on keyboard Done / leaving the box.
- Remembered per website; all tabs on that site and later visits use it; other sites stay 100%.

Earlier (v8-v13): address bar shows site name only + Copy/Delete/Paste/Go/Close strip,
download button with fill progress, dark status bar icons, release-APK build.yml,
candy app icon, tab count in a rectangle.
